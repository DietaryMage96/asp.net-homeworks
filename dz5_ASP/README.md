# Movie API (`dz5_ASP`)


## Інструкція запуску

1. Відкрити рішення `less10.slnx` у Visual Studio.
2. Перевірити рядок підключення `"def"` у `less10/appsettings.json` (MS SQL Server LocalDB).
3. Застосувати міграції БД у **Package Manager Console** (Default project: `Dll`):
   ```powershell
   Update-Database
4. Запустити проєкт less10 (F5) та відкрити Swagger у браузері (/swagger).
