\# Movie API — Контракти та валідація (ДЗ 4)



\## Інструкція запуску

1\. Клонувати репозиторій та відкрити рішення у папці `dz4\_ASP`.

2\. У файлі `less10/appsettings.json` вказати актуальний рядок підключення `"def"`.

3\. Застосувати міграції БД у Package Manager Console:

&#x20;  ```powershell

&#x20;  Update-Database

&#x20;  ```

4\. Запустити проєкт (`F5`) та відкрити Swagger UI за адресою `/swagger`.



\---



\## Результати перевірки через Swagger



\### Тест 1 — Успішний запит (`200 OK`)

\* \*\*Запит:\*\* `POST /api/Movie` з коректними даними.

\* \*\*Очікуваний та фактичний результат:\*\* Статус `200 OK`, фільм збережено в БД із присвоєним сервером `Id`.

!\[Test 1](images/Test%201.jpg)



\### Тест 2 — Порожня назва (`400 Bad Request`)

\* \*\*Запит:\*\* `POST /api/Movie` зі значенням `"title": ""`.

\* \*\*Очікуваний та фактичний результат:\*\* Статус `400 Bad Request` (`Title is required`), дані в БД не збережено.

!\[Test 2](images/Test%202.png)



\### Тест 3 — Надто довгий текст (`400 Bad Request`)

\* \*\*Запит:\*\* `POST /api/Movie` з перевищенням ліміту символів у полі (`\[StringLength]`).

\* \*\*Очікуваний та фактичний результат:\*\* Статус `400 Bad Request` (`Max length is 100` / `500`), дані в БД не збережено.

!\[Test 3](images/Test%203.png)



\### Тест 4 — Недопустиме числове значення (`400 Bad Request`)

\* \*\*Запит:\*\* `POST` / `PUT` із рейтингом або роком випуску поза межами `\[Range]`.

\* \*\*Очікуваний та фактичний результат:\*\* Статус `400 Bad Request`, дані в БД не збережено.

!\[Test 4](images/Test%204.png)



\### Тест 5 — Звернення до відсутнього фільму (`404 Not Found`)

\* \*\*Запит:\*\* `GET` / `PUT` / `DELETE` за неіснуючим `id`.

\* \*\*Очікуваний та фактичний результат:\*\* Статус `404 Not Found` (`Movie not found`).

!\[Test 6](images/Test%206.png)
